## Проект

- Что это: веб-инструмент для дизайнеров. Даёшь цвет (HEX, пипетка или фото) — получаешь палитру до 8 цветов для Figma и кода. Пет-проект nuforms lab.
- Сайт: https://c3lab.vercel.app — единственный адрес, без редиректов. Старые `complimentary.vercel.app` и `complimentary-color-creator.vercel.app` удалены, `c3.vercel.app` занят.
- Репозиторий: https://github.com/aukisun/c3lab, ветка `main`. Других веток нет; v1 — тег `v1`.
- Деплой: Vercel, проект `c3` в команде `nuforms`, автоматически при каждом push в `main`. Vercel-коннектору нужен доступ к команде nuforms, иначе он отвечает 403.

## Архитектура

Всё приложение — **один файл `index.html`** (~1150 строк): разметка, `<style>` и `<script>` внутри. Без сборки, без npm, без зависимостей, кроме Google Fonts: Syne и Space Mono грузятся сразу, шрифты холста (`CV_FONTS`) — только когда их выбрали.

**Так и оставить.** Не добавлять фреймворки, бандлеры, `package.json`, CDN-библиотеки без явного согласия Иванко.

Карта `index.html` (номера строк плывут — ищи по именам):

- **CSS-токены в `:root`.** `--h` — оттенок текущего базового цвета, его ставит JS, и вся страница перекрашивается под палитру. Светлая тема по умолчанию; тёмная — через `prefers-color-scheme` и `[data-theme="dark"]`. Брейкпоинт мобильной вёрстки — `max-width:640px`.
- **Разметка**: `header` (знак + кнопка темы) → `nav.modes` (Upload / Code / Picker / Canvas) → панели `#panel-*` → `#harmonies` → `#stage` (палитра-капсулы) → кнопки экспорта → `#weights` (вес цветов фото) → `#canvasLab` (холст) → `footer.site-foot`. Вкладка Canvas — отдельная страница: класс `body.canvas-view` прячет панели ввода, капсулы, экспорт и `#weights` и показывает `#canvasLab`; строка гармоний остаётся.
- **Скрипт**:
  - цветовая математика: `hexToRgb`, `toLab`, `dE`, `describe()`, справочники `PANTONE` и `NAMES`;
  - OKLCH-движок: `hexToOklch`, `oklch(L,C,H)` — выход за гамму исправляется снижением chroma;
  - `HARMONIES` — объект гармоний. У каждой есть `name`, `rule`, `build(b,m)`, который возвращает 8 цветов; слот с индексом 1 — `null`, туда встаёт базовый цвет. **Вкладки гармоний строятся автоматически** из `Object.entries(HARMONIES)`, плюс вкладка Photo;
  - `buildPalette`, `extract(img,k)` — цвета из фото, `render` / `layout` / `theme`;
  - загрузка: `handleFile()`. Файл, который браузер не может прочитать, не должен проваливаться молча — `img.onerror` показывает тост (для HEIC отдельная подсказка: Chrome-браузеры его не читают, Safari читает). После чтения поле `#fileInput` очищается, иначе повторный выбор того же фото не срабатывает;
  - `fromBase(hex)` — главная точка входа;
  - пипетка: `pickFromScreen()` через браузерный EyeDropper — мышка берёт цвет в любом месте экрана. Открывается сразу при клике по вкладке Picker (клик пользователя обязателен для EyeDropper) и кнопкой `#eyeBtn`. Есть только в Chromium-браузерах; в Safari и Firefox кнопка спрятана и остаётся квадрат цвета `#sv` + `#hue`. Квадрат и кнопка стоят в одну строку, иначе панель высотой 136 px наезжает на гармонии на телефоне;
  - экспорт: `#copySvg` (слои с именами для Figma), `#copyCss` (`--color-100…800`), `#copyJson`. Копирование идёт через `copy(text,msg)` с тостом;
  - **холст** (всё с префиксом `cv`, состояние в объекте `cv`): `cvSync()` вызывается из `render()`. Панель намеренно минимальная — так решил Иванко, лишнего не добавлять: стиль, три цвета (`cv.slots`: Background, Form 1, Form 2) и текст (поле, шрифт `CV_FONTS`, цвет — четвёртый слот, выравнивание, On paper / Over shapes), экспорт Copy SVG и Copy PNG. Убраны и не возвращать: выбор формата (всегда 3:4, 1200×1600), Shuffle, Paper/Ink, кружки «pick 2–4», стиль Blocks. Слот хранит `src`: индекс палитры (цвет следует за палитрой), `'white'`, `'black'` или `null` (введённый HEX остаётся); `cvDefaults()` даёт стартовые цвета. Композиции фиксированные, по одной на стиль: `CV_CIRCULAR` (модуль 4×5) и `CV_CONSTRUCT` (доли арт-области); Form 1 — крупные формы, Form 2 — акценты. `cvDraw()` собирает `cv.svg` (с текстом) и `cv.art` (без текста); `cvPng()` рисует `cv.art` на канвасе 2× и пишет текст загруженным веб-шрифтом — иначе в PNG шрифт был бы системный.

## Правила продукта

1. Гармонии считаются в **OKLCH**, не в HSL. Цвет вне гаммы — снижаем chroma, сохраняя hue и lightness.
2. Цвета из фото — **реальные пиксели**. Ничего не усреднять и не придумывать промежуточных цветов.
3. Новые цвета интерфейса — только через CSS-переменные. Каждую правку проверять в светлой **и** тёмной теме.
4. Доступность: `role` и `aria-*` как в существующей разметке, фокус-кольца через `body.kbd`, уважать `prefers-reduced-motion`.
5. Тексты интерфейса — на английском, в тоне существующих: коротко, `·` как разделитель. В UI пишется «color» (US), README исторически пишет «colour» — не смешивать внутри одного файла.
6. Copy SVG должен вставляться в Figma с именованными слоями. Меняешь палитру или рендер — проверь экспорт.
7. Версия «C³ Engine vN» в футере меняется только при крупной переделке движка и только по согласованию.

### Ориентиры качества

- **Палитры — как на ColorHunt:** кинематографичные, реалистичные сочетания. Пример: от красного `#F63049` ждём глубокие синие и фиолетовые, а не розовые вариации того же красного.
- **Извлечение из фото — как Figma Image Color Picker.** Контрольный снимок lumeis должен давать `#F6F2E7 / #240918 / #C8DEF3 / #F3F86A`. Самого снимка в репо нет — попроси у Иванко.
- **Текстурные фото — второй контрольный снимок:** Мариенкирхе в Любеке (кирпич, черепица, небо), Иванко присылал 19 ноября 2026. Должен давать 8 цветов с терракотой и кирпичом — `#BEC0CF / #A0AED3 / #CA5038 / #A54934 / #883724 / #6A281C / #431811 / #0A0406`, — а не 3 цвета без красного. Снимка в репо нет — попроси у Иванко.
- Раньше цвета из фото брались k-means по размытой миниатюре и выходили серыми и грязными. Не возвращаться к усреднению.
- До 19 ноября 2026 порог 0.6% проверялся для каждой мелкой «корзинки» цветов отдельно, и текстура (кирпич — 32% фото, рассыпанные по 1316 корзинкам) пропадала. Теперь `extract()` сначала собирает похожие корзинки в группы и проверяет порог для группы; цвет группы — реальный пиксель, ближайший к её центру. Не возвращать проверку по корзинкам.

## Проверка перед словом «готово»

1. Запусти локальный сервер: `python3 -m http.server 8000` и открой http://localhost:8000 в Browser pane.
2. В консоли нет ошибок.
3. Работают все три входа: Code, Upload (с реальной фотографией), Picker (пипетка и квадрат цвета). Саму пипетку в скрытом браузере не кликнуть — подменяй `EyeDropper.prototype.open` ответом с HEX и честно говори, что настоящий клик по экрану проверяет Иванко.
4. Все гармонии и вкладка Photo после загрузки фото.
5. Светлая и тёмная тема.
6. Ширина 375 px (телефон).
7. Copy SVG / CSS / JSON дают валидный результат.

Палитры и извлечение из фото проверяй на цифрах (HEX) и реальных референсах из «Ориентиров качества», а не на глаз.

Не можешь что-то проверить — так и скажи, не пиши «всё работает».

## Git и деплой

- **Push в `main` = сразу продакшн.** Коммитить можно сам; пушить — только после явного «пушь» от Иванко или через `/ship`.
- **Автор коммитов — только `aukisun <aukisun@gmail.com>`.** Перед первым коммитом в сессии проверь `git config user.email`. Коммиты v2 (октябрь 2026) подписаны `Claude <noreply@anthropic.com>` — так вышло до переезда, историю не переписываем.

- Никогда без спроса: force push, переписывание истории, удаление веток, `git reset --hard`.
